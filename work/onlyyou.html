사례 06 · (주)임팩트크래프트

온리유

회원가입 이탈을 줄이기 위한 온보딩 개선

기간
2024.08 ~ 2024.09
소속
(주)임팩트크래프트
역할
화면 기획, UX/UI 디자인
팀
디자인 1명(본인), 풀스택 개발 2명
개선 전후 회원가입 화면 (인물 사진 흐리게)

배경

온리유는 결혼을 생각하는 사람들을 위한 결혼정보 플랫폼으로, 이상형 데이터를 바탕으로 1:1 매칭을 제공합니다.

기존 가입 과정의 이탈률은 67%였고, Hotjar로 사용자가 어디서 나가는지 살펴봤습니다.

문제

  • 가입 신청을 마치기까지 단계가 많아, 신규 사용자는 평균 3분이 걸렸습니다.
  • 서비스에 대한 신뢰가 쌓이기 전에 얼굴 사진 여섯 장과 많은 정보를 요구해, 작은 부담에도 쉽게 이탈했습니다.

해결

  • 바텀시트를 활용해 입력 흐름을 두 단계로 나누고, 전체 페이지 수를 줄였습니다.
  • 고객 리뷰를 앞에 보여 주고, 사진 업로드 수를 줄이고, 정보 보안 문구를 강조했습니다.
  • 외부 링크로 나가던 사진 가이드는 페이지 안에 넣었습니다.
바텀시트 입력 흐름
리뷰 강조·사진 업로드 화면

결과

  • 가입 이탈률 감소와 서비스 신뢰도 향상을 기대한 개선안입니다. 개선 후 수치는 확인하지 못했습니다.
  • 대표님 피드백: “결과물이 굉장히 만족스럽다고 말씀드리고 싶어요.”
